# Документация по использованию эмулятора мезонов

Библиотека предоставляет инструменты для построения, обучения и использования суррогатной модели (эмулятора) на базе многозадачных гауссовских процессов (GPyTorch)[cite: 1]. Эмулятор аппроксимирует расчет спектра масс мезонов тяжелым симулятором и позволяет быстро вычислять предсказанные массы, значение $\chi^2$ и его аналитические градиенты по параметрам анзатса[cite: 1].

---

## Архитектура и порядок работы

Процесс взаимодействия с библиотекой состоит из двух последовательных этапов[cite: 1]:
1. **Обучение эмулятора (`Emulator_Trainer`)** — генерация начальных выборок методом латинского гиперкуба, первичное обучение модели и последующее активное (адаптивное) обучение по критерию максимальной неопределенности (дисперсии)[cite: 1]. Итоговые веса и параметры нормализации сохраняются в `.pth` файл[cite: 1].
2. **Инференс и оптимизация (`Emulator_Worker`)** — загрузка обученной модели из файла, быстрое предсказание масс мезонов, а также вычисление невязки $\chi^2$ и градиента $\nabla_{\theta}\chi^2$ для алгоритмов градиентного спуска или MCMC-семплирования[cite: 1].

---

## 1. Обучение модели: класс `Emulator_Trainer` (`constructor.py`)

Класс инкапсулирует весь пайплайн обучения суррогата[cite: 1].

### 1.1. Параметры инициализации `__init__`

```python
from constructor import Emulator_Trainer

trainer = Emulator_Trainer(
    Anzats,                             # Класс/функция анзатса метрической деформации[cite: 1]
    bounds_list,                        # Список списков с границами параметров: [[min_1, max_1], ...][cite: 1]
    gp_model=MultitaskGPModel,          # Класс GP модели (по умолчанию MultitaskGPModel)[cite: 1]
    gp_likelihood=gpytorch.likelihoods.MultitaskGaussianLikelihood, # Класс правдоподобия[cite: 1]
    k_sw_impact=1.0,                    # Фиксированный физический параметр симулятора[cite: 1]
    L=1.0,                              # Фиксированный масштаб симулятора[cite: 1]
    simulator=simulator,                # Функция симулятора[cite: 1]
    anzats_constants=None,              # Дополнительные константы для анзатса (опционально)[cite: 1]
    start_train_per_dim=10,             # Число начальных обучающих точек на одну размерность входа[cite: 1]
    valid_per_dim=50,                   # Число валидационных точек на одну размерность входа[cite: 1]
    meson_masses_number=12,             # Размерность выхода симулятора (количество масс мезонов)[cite: 1]
    bound_percent=0.5,                  # Целевой порог максимальной относительной ошибки в процентах[cite: 1]
    max_iters=50000,                    # Максимальное число итераций адаптивного обучения[cite: 1]
    show_metrics=False,                 # Флаг отображения метрик[cite: 1]
    validation_path="validation_data.csv", # Путь для сохранения валидационных данных[cite: 1]
    emulator_path="emulator_state.pth"  # Имя файла для сохранения обученного состояния эмулятора[cite: 1]
)
```

### 1.2. Запуск процесса обучения

Для пользователя весь процесс выполняется вызовом одного метода[cite: 1]:

```python
trainer.Train()
```

#### Что выполняется под капотом:
1. **`initialise_validation_set()`**: методом латинского гиперкуба генерируется валидационный набор (`valid_per_dim * dim` точек), входы приводятся к единичному гиперкубу $[0, 1]^d$, а выходы стандартизируются с сохранением среднего $\mu_y$ и дисперсии $\sigma_y$[cite: 1].
2. **`initialise_emulator()`**: создается начальный обучающий набор (`start_train_per_dim * dim` точек), инициализируются модель и правдоподобие, выполняется начальная подгонка гиперпараметров оптимизатором L-BFGS (`trainBFGS`)[cite: 1].
3. **`train_emulator()`**: цикл адаптивного обучения[cite: 1]:
   * На каждом шаге метод `adaptive_learning_using_mse()` находит точку в пространстве параметров с максимальной дисперсией предсказания модели (через оптимизацию с помощью Adam)[cite: 1].
   * В найденной точке вызывается тяжелый симулятор[cite: 1].
   * Новая точка добавляется в обучающий датасет, веса GP дообучаются через L-BFGS[cite: 1].
   * Рассчитываются валидационные метрики: MSLL (Mean Standardized Log Loss), RMSE и максимальная относительная ошибка в процентах[cite: 1].
   * Цикл завершается при достижении максимальной ошибки $\le$ `bound_percent` или по исчерпании `max_iters`[cite: 1].
4. **`check_ebalo()`**: в консоль выводятся финальные метрики; если MSLL > 0 или ошибка превышает целевую, выводится предупреждение и запрашивается подтверждение продолжения (`Y`/`N`)[cite: 1].
5. **`save_emulator_state()`**: веса модели, веса лайклихуда, обучающие точки и параметры масштабирования `y_mu`, `y_std` сохраняются в словарь в файл `emulator_path`[cite: 1].

## 2. Использование эмулятора: класс `Emulator_Worker` (`emulator_worker.py`)

Класс используется после успешного обучения для работы с моделью в прикладных задачах (подгонка параметров под эксперимент)[cite: 1].

### 2.1. Инициализация объекта `__init__`

```python
from emulator_worker import Emulator_Worker

worker = Emulator_Worker(
    target_masses=target_masses,               # torch.Tensor: экспериментальные значения масс[cite: 1]
    target_masses_errors=target_masses_errors, # torch.Tensor: погрешности экспериментальных масс[cite: 1]
    bounds_list=bounds_list,                   # Список диапазонов параметров (совпадающий с обучением)[cite: 1]
    gp_model=MultitaskGPModel,                 # Класс GP модели[cite: 1]
    gp_likelihood=gpytorch.likelihoods.MultitaskGaussianLikelihood, # Класс лайклихуда[cite: 1]
    bound_percent=0.5,                         # Целевая погрешность[cite: 1]
    emulator_path="emulator_state.pth"         # Путь к файлу с весами модели[cite: 1]
)
```

### 2.2. Обязательная загрузка состояния модели

Перед вызовом любых расчетных методов необходимо восстановить обученное состояние[cite: 1]:

```python
worker.Initialise_emulator()
```
*Метод загружает веса модели, параметры лайклихуда, обучающую выборку, а также параметры стандартизации `y_mu` и `y_std`[cite: 1].*

### 2.3. Расчетные методы

#### Вычисление $\chi^2$ и градиента: `return_xi_squared_and_grad(parametrs)`
Основной метод для процедур оптимизации и подгонки параметров[cite: 1].

```python
xi_sq, grad = worker.return_xi_squared_and_grad(parametrs)
```
* **Входные данные**: `parametrs` — список, массив NumPy или `torch.Tensor` размерности `(D,)` или `(1, D)` с физическими параметрами анзатса[cite: 1].
* **Механика**:
  1. Входные параметры автоматически масштабируются в единичный куб $[0, 1]^d$ по `bounds_list`[cite: 1].
  2. Модель делает предсказание, математическое ожидание дестандартизируется обратно в физические массы мезонов[cite: 1].
  3. Вычисляется функционал невязки:
     $$\chi^2 = \sum_{i=1}^{N} \left( \frac{m_i^{\text{pred}} - m_i^{\text{target}}}{\sigma_i^{\text{target}}} \right)^2$$[cite: 1]
  4. Через `torch.autograd.grad` вычисляется вектор градиента $\nabla_{\text{parametrs}} \chi^2$[cite: 1].
* **Возвращаемое значение**: кортеж `(float, torch.Tensor)`, где первое значение — скаляр $\chi^2$, второе — тензор градиентов той же размерности, что и входные параметры[cite: 1].

#### Прямое предсказание спектра масс: `return_mass_values(parametrs)`
Используется, когда необходимо получить только физические значения масс без расчета градиентов[cite: 1].

```python
masses = worker.return_mass_values(parametrs)
```
* **Входные данные**: `parametrs` — параметры анзатса в физическом масштабе[cite: 1].
* **Возвращаемое значение**: `torch.Tensor` размерности `(meson_masses_number,)` с предсказанными массами мезонов (в исходных физических единицах)[cite: 1].

## 3. Полный пример пайплайна (End-to-End)

Ниже приведен полный сценарий: обучение эмулятора с последующей подгонкой параметров через градиентный спуск[cite: 1].

```python
import torch
from constructor import Emulator_Trainer
from emulator_worker import Emulator_Worker

# -------------------------------------------------------------------------
# Шаг 0: Подготовка физических параметров и анзатса
# -------------------------------------------------------------------------
# Пример: 3 параметра анзатса и их границы поиска
bounds = [
    [-1.5, 1.5],
    [0.1, 2.0],
    [0.0, 10.0]
]

# Функция или класс анзатса, принимающая тензор параметров
def my_anzats(params):
    # Возвращает объект деформации метрики для симулятора
    return params

model_checkpoint = "meson_emulator.pth"

# -------------------------------------------------------------------------
# Шаг 1: Обучение эмулятора (выполняется один раз)
# -------------------------------------------------------------------------
trainer = Emulator_Trainer(
    Anzats=my_anzats,
    bounds_list=bounds,
    k_sw_impact=1.0,
    L=1.0,
    bound_percent=0.5,        # Целевая погрешность 0.5%
    start_train_per_dim=10,
    valid_per_dim=30,
    max_iters=500,
    emulator_path=model_checkpoint
)

# Запуск генерации выборок, первичного фита и адаптивного дообучения
trainer.Train()

# -------------------------------------------------------------------------
# Шаг 2: Использование обученного эмулятора для подгонки
# -------------------------------------------------------------------------
# Экспериментальные массы 12 мезонов и их погрешности
target_m = torch.tensor(
    [0.77, 0.78, 1.02, 1.20, 1.30, 1.40, 1.50, 1.60, 1.70, 1.80, 1.90, 2.00],
    dtype=torch.double
)
target_err = torch.full_like(target_m, 0.05, dtype=torch.double)

# Создание воркера
worker = Emulator_Worker(
    target_masses=target_m,
    target_masses_errors=target_err,
    bounds_list=bounds,
    emulator_path=model_checkpoint
)

# Обязательная инициализация (чтение весов из checkpoint)
worker.Initialise_emulator()

# Пример: оптимизация параметров анзатса методом градиентного спуска
params = torch.tensor([0.0, 1.0, 5.0], dtype=torch.double)
learning_rate = 0.01

for step in range(50):
    # Вычисление chi^2 и градиента
    chi2, grad = worker.return_xi_squared_and_grad(params)
    
    if step % 10 == 0:
        print(f"Шаг {step:2d} | Chi2: {chi2:.4f} | Градиент: {grad.numpy()}")
    
    # Градиентный шаг
    with torch.no_grad():
        params -= learning_rate * grad

# Получение итогового спектра масс
final_masses = worker.return_mass_values(params)
print(f"\nИтоговые параметры: {params.numpy()}")
print(f"Предсказанные массы: {final_masses.numpy()}")
```
